🎉 欢迎使用 Proxy Version

让我们快速了解如何使用

1

📜 申请 SSL 证书

大多数协议需要 SSL 证书来加密流量。

为什么需要证书？
  • 保护数据传输安全
  • 伪装成正常 HTTPS 网站
  • 避免被检测和封锁

💡 如果使用 Reality 协议则无需证书

2

🌐 创建代理节点

选择适合的协议创建节点：

推荐协议：
  • VLESS Reality - 无需域名，最强抗检测
  • Hysteria2 - 超高速度，适合视频
  • Trojan - 简单高效，兼容性好
3

📱 配置客户端

创建节点后，将配置导入客户端软件：

  • iOS: Shadowrocket, Quantumult X
  • Android: v2rayNG, NekoBox
  • Windows: v2rayN, Clash
  • macOS: ClashX, V2rayU

创建节点

申请SSL证书

⚠️ 证书用途说明

  • 用于加密节点通信，伪装 HTTPS 流量
  • 证书将自动续签（90天有效期）
  • 需要将域名解析到本服务器 IP

💡 Cloudflare API Token 获取方法：

  • 登录 Cloudflare → 右上角头像 → My Profile
  • API Tokens → Create Token
  • 选择 "Edit zone DNS" 模板
  • Zone Resources: 选择您的域名
如果使用 Global API Key 则必填
