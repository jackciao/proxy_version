让我们快速了解如何使用

1

📜 申请 SSL 证书

大多数协议需要 SSL 证书来加密流量。

为什么需要证书？
  • 保护数据传输安全
  • 伪装成正常 HTTPS 网站
  • 避免被检测和封锁

💡 如果使用 Reality 协议则无需证书

2

🌐 创建代理节点

选择适合的协议创建节点：

推荐协议：
  • VLESS Reality - 无需域名，最强抗检测
  • Hysteria2 - 超高速度，适合视频
  • TUIC - 基于 QUIC，低延迟高性能
3

📱 配置客户端

创建节点后，将配置导入客户端软件：

  • iOS: Shadowrocket, Quantumult X
  • Android: v2rayNG, NekoBox
  • Windows: v2rayN, Clash
  • macOS: ClashX, V2rayU

创建节点

⚠️ 端口 443 已被占用

选择特定 IP 可解决 443 端口冲突问题

  • 用于加密节点通信，伪装 HTTPS 流量
  • 证书将自动续签（90天有效期）
  • 需要将域名解析到本服务器 IP

  • Zone Resources: 选择您的域名
如果使用 Global API Key 则必填

📖 WARP 配置教程

                    
                

                

                    

                        
方法一：WARP+ 订阅（付费）

                        
    
                            
  1. 在手机上下载 1.1.1.1 (Cloudflare WARP) App
    2. 
                            
  2. 打开 App → 点击右上角菜单 → 账户
    3. 
                            
  3. 选择 升级到 WARP+，完成订阅（约 $4.99/月）
    4. 
                            
  4. 订阅后点击 管理账户 → 按键 查看 License Key
    5. 
                        


                        
方法二：Cloudflare Zero Trust（推荐，免费）

                        

                            
✨ Zero Trust 提供比普通 WARP 更好的连接质量，每月 50 用户免费

                        

                        
    
                            
  1. 访问 Cloudflare Zero Trust 控制台
                            
    2. 
                            
  2. 使用 Cloudflare 账户登录，创建团队（输入团队名称）
    3. 
                            
  3. 进入 Settings → WARP Client →
                                Device enrollment
                            
    4. 
                            
  4. 添加 Enrollment Rule，设置允许的邮箱或域名
    5. 
                            
  5. 在手机 1.1.1.1 App 中：设置 → 账户 →
                                使用其他团队登录
                            
    6. 
                            
  6. 输入团队名称，完成邮箱验证即可使用
    7. 
                        


                        
方法三：手动导入配置

                        

                            如果您已有 WARP WireGuard 配置（如从其他设备导出），可以使用"导入配置"功能：
                        

                        
    
                            
  1. 在 WARP App 中导出 WireGuard 配置
    2. 
                            
  2. 提取 PrivateKey、Address (IPv4/IPv6)
    3. 
                            
  3. 在本系统中使用 API 导入配置
    4.
